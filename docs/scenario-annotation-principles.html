一、一句话原则

原文有内容就一字不改，缺信息处补感官/选项/分支，元术语全删，战斗/检定/flag 触发点单独标记。

跟之前 LLM "卷宗化改编" 的差别 — 之前是压缩 + 加味, 现在是保留 + 在稀疏处加味。信件、对话、资料这种信息密集场景，一个字都不许 LLM 改。

七、段长度规则（你新追加）

每个 narrate ≤ ~60 字 / 1-2 句，超过就拆页。扩写后要有足够文本量讲清 "看到什么 + 感受"，不能只甩一句。
  • verbatim 段：按原文标点天然分页（句号/问号/感叹号），单段过长自动拆
  • expand A 加感官：1 段原文骨架 → 3-4 段扩写（动作、视觉、内心、结果），每段 ≤ 60 字
  • expand B 探索动作：每个按钮的成功 narrate 至少 3 段，给"探索的获得感"，不能只显示一句"找到 X"
  • 对话：长对话拆成多条 dialogue 行，每条 ≤ 60 字，speaker 在每行前重复出现
