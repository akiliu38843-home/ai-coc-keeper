WebGAL 模板生态调研

项目 · ai-coc-keeper  |  日期 · 2026-05-29  |  场景 · 决定"角色卡按钮"走轻路线还是等社区现成

一句话结论

没有现成模板能直接拿来用, 该自己写还得自己写. 但好消息是, "轻路线"的 2 小时 JS 注入方案不浪费 —— 官方模板系统目前只支持改样式 (颜色 / 字号 / 间距), 不支持加新 UI 组件. 我们想要的底部角色卡按钮 = 新组件, 走自己注入是正确选择.

1. 调研口子 (5 个)

渠道找到了啥
官方文档 / 博客 WebGAL 4.5.5 有"自定义 UI 模板"功能, 但只支持改样式 (颜色 / 字号 / 间距), 不支持加新组件
官方 RFC 设计稿 明确写"有限的 CSS 编辑", 没规划插件化 / 第三方组件接入
GitHub 全部 fork (gh API 拉了 60+ 个) 全是 mirror 或个人自用, 没人公开做过状态栏 / 角色卡这种新 UI
跟 TRPG 相关的 fork 0 个. 跑团相关项目 (wiio12/trpg, TRPG-Replay-Generator) 都跟 WebGAL 无关
官方 issue (#719 支持多种模板) open 状态没人接, 也没排上版本

2. 官方模板能改啥不能改啥

WebGAL 4.5.5 官方模板编辑器实际能力 (来源: dev-note-3):

能力支持?
改颜色 / 字号 / 字体 / padding / margin / hover 效果✓ 支持
改 textbox / 标题界面 / 选项按钮的视觉✓ 支持
加一个全新的"状态栏" div✗ 不支持
加一个底部菜单新按钮✗ 不支持
写自己的 React 组件挂上去✗ 不支持
读 WebGAL 内部 state 自己渲染面板✗ 不支持
官方原话 (dev-note-3): "font color, font size, background color or images, transformations, padding and margins". 范围被刻意限制 — RFC2 称之为"有限的 CSS 编辑".

3. 模板共享的现状

  • 官方 marketplace 没有
  • awesome-webgal 列表 没有
  • 用户私藏模板大多在 官方 QQ 群 709293432 里私下流转, 不在公开网络
  • 没看到任何中文社区 (B 站 / 小红书 / cnmods) 有"WebGAL 模板包"分享潮

4. 顺手发现的 2 个能参考的 fork

仓库star做了什么 / 为什么对我们有参考价值
Project-AnyGO/WebGAL-PartialEngine 6 改了底层渲染, 支持 alpha 通道录屏 + 4K. 验证了 WebGAL 可深度改造, 不是封闭引擎.
KonshinHaoshin/webgal_mano 5 分层立绘渲染, 是 PIXI.js 层 mod. 思路接近"如何在 WebGAL 里加自己的渲染层".

5. 决策建议

照原计划走 轻路线, 2 小时内出第一版底部角色卡按钮. 理由:

  1. 等官方模板系统升级到支持新组件, 看路线图 (4.5.0 才刚完成 title+textbox 2 个组件) 至少还要好几个版本, 不知道猴年马月
  2. 加 QQ 群淘私藏模板 ROI 低, 而且我们要的是新组件型 mod, 群里基本是样式包
  3. 我们的 "TRPG 跑团 UI" 在 WebGAL 用户里是小众 niche, 没人会替我们做好
